# PULSE — atualizações

Este repositório guarda **somente versões compiladas** do PULSE (sampler para tocar ao vivo)
e a lista de versões (`manifest.json`) lida pelo atualizador do app.
O código-fonte do PULSE não fica aqui.

- **Programa:** em *Releases* (`PULSE-app-<versão>.zip`).
- **Atualizar:** dentro do PULSE, *Ajustes → Atualizações → Verificar / Instalar*.
